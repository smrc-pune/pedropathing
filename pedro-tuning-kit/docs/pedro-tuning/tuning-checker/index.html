4. Do the pod offsets match the robot?

5. Compare runs

Spread = (largest − smallest) ÷ average. Our thresholds: up to 10% fine, up to 25% look again, above 25% re-run. The value farthest from the others is shaded.

6. Averaged ForesightConfig

Each value is the average of the runs that have it, in the same layout AutoTune writes. Averaging keeps the large ÷ small kP ratio unchanged.
